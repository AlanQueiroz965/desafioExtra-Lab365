## 🚀 Etapas de Desenvolvimento

O projeto foi construído seguindo as seguintes fases:

1.  **Planejamento:** Definição da estrutura da página (Header, Hero, Sobre, Contato e Rodapé).
2.  **Estruturação HTML:** Criação da marcação semântica para garantir acessibilidade.
3.  **Estilização CSS:** Implementação do design responsivo (Mobile First), garantindo que o site funcione bem em celulares e computadores.
4.  **Interatividade:** Adição de scripts simples para validação de formulários.
5.  **Finalização:** Ajustes de layout e publicação da página para acesso via web.
